# Картинки Bubudoo: правила

Все слои: PNG (или WebP) с прозрачным фоном, ОДИН размер холста для всех (сейчас 1254x1254),
предмет нарисован сразу на своём месте (без обрезки), координаты не нужны.

## Папки
- `logo.*`, `favicon*`, `apple-touch-icon.png`, `android-chrome-*`, `maskable-*`, `mstile-*` — логотип и иконки.
- `empty/<герой>/<цвет>.png` — пустые базы без лица. Каждый цвет меха = отдельный файл.
  Например: `empty/bubu/classic.png`, `empty/dudu/caramel.png`.
- Категории (по одной папке на настройку): `eyes`, `mouth`, `cheeks`, `outfit`, `hats`,
  `accessories`, `props`, `backgrounds`.

## Общее и личное
- Общий предмет (для обоих героев): `<категория>/<имя>.png`, например `hats/bow.png`.
- Только для одного героя, или у героя своя версия: `<категория>/<герой>/<имя>.png`,
  например `eyes/dudu/dots.png`. Если есть и общий, и личный файл с одним именем, берётся личный.

## Предмет из двух слоёв
Если часть предмета должна быть ЗА персонажем (хвост шарфа, ниточка шарика):
`<имя>.png` — перед персонажем, `<имя>-back.png` — за ним.

## Имена файлов
Латиница, маленькие буквы, дефис вместо пробела: `sunglasses.png`, `party-hat.png`.

## Важно для Дуду
Холст, поза, размер и положение головы, глаз, рта и щёк у Дуду должны совпадать с Бубу
(глаза ~39% и 61% ширины на высоте ~47%, рот ~50% / 51%, щёки ~31% и 69% на высоте ~54%).
Тогда большая часть слоёв (одежда, шапки, очки, лицо) работает для обоих героев.
